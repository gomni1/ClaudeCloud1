# SPEC: the grammar's clock (PHYS2, 31 Oct 2026, revision 2)

Preregistration. This file is frozen by recording its SHA-256 in RESULTS.md before any new
simulation code runs. After the freeze no target, grid, threshold or criterion changes; a revision
is a new claim, logged as one, and every failure stays on the record.

**Register.** The ODE and the Markov chain below are effective-register summaries of step processes.
Neither is claimed to be the underlying process; both are coarse-grained descriptions of it.

Labels are neutral throughout: C (Contact-active), V (Void-active), L (Loosened), P (persistence-locked).
Notation: `span` = log10(max rate / min rate) over the rates in use; on the closed level the rates in
use are k1, k2, k3, k5, k6, k7, k8, k10, k11 (k9 and k12 are not used).

## K1. Where clocks live (cap 2 CPU-hours, cores 2-3)

PR 4's M2 code (`ginst.m2.process`), classifier and seeding unchanged, with one declared addition:
**a per-draw cap of 120 CPU-seconds** (each batch of draws runs in a forked child; before each draw
the child sets RLIMIT_CPU to its current CPU time + 120 s; a draw killed at the cap is recorded as
`unresolved: cpu cap`). The addition can only lower sensitivity; it cannot create a cycle.

Sub-runs, in this order, within the 2 CPU-hour cap (CPU = sum of child CPU from wait4 rusage):

- **K1b (C1 search, moderate-rate box).** Seed 31102026 (`default_rng([31102026, i])` for the draw,
  and M2's start generator with SEED = 31102026). All-neighbours count only; the levels alternate:
  i even = open, i odd = closed. Each of the 11 rates log10 k ~ U(-1, 1) (one call drawing 11 values,
  as PR 4); then m, kr, kc, T drawn exactly as PR 4 (`integers(2, 13)`, `integers(1, m+1, 2)`,
  `10**uniform(-1, 2)`). Draws i = 0 .. 39999 (20 000 per level). Every span <= 2 by construction.
- **K1a (census).** PR 4's draw generator, all-neighbours variants only (i % 4 in {2, 3}),
  draws 41100 .. 99999.
- **K1c (second pass).** Every unresolved start end state (PR 4 draws 0-41099 and the new K1a/K1b
  draws) is re-integrated from its end state with `integ.run_starts` for 10 x t_end and classified by
  the same classifier, same 120 s cap, in this order until the K1 cap: (1) all closed-level ones
  (PR 4 first, then K1a); (2) K1b's (closed then open); (3) open-level ones from PR 4 and K1a, in a
  random order fixed by `default_rng(31102026).permutation`.
  PR 4's committed draw records do not store start end states; the end states are regenerated by
  re-running PR 4's draw (deterministic, same code and seeds) inside the second pass, and that CPU
  counts toward K1.
- **Verification** of every periodic end state exactly as PR 4's M4 (`ginst.m4.verify_cycle`):
  LSODA and Radau periods agree to 1e-6, nontrivial Floquet moduli < 1 - 1e-6 (nontrivial = all
  but the modulus nearest 1 on the open level; all but the two nearest 1 on the closed level, where
  the conservation law adds one).
- **Report** per level and per sub-run: draws run, number and fraction with a verified periodic end
  state, per cycle m, kr, kc, span, period, C range; for a sub-run with no hit the 95% upper bound
  3/n. Census totals combine K1a with PR 4's draws 0-41099 (all-neighbours variants).
- **C1 (question).** Is there a verified cycle whose rates in use span <= 2 decades?
  Yes: give the draw. No: none in the full K1b run; give the bound 3/n and state that this is not a
  proof of absence. Underdetermined: the cap was reached before K1b finished.

## K2. Survival toward moderate rates, and birth (cap 1 CPU-hour)

- **Rate homotopy.** For draw 12051 and, once K1 has finished, at most 2 further verified K1 cycles
  (smallest span): ln k(lambda) = (1 - lambda) ln k + lambda mean(ln k) over the rates in use,
  lambda from 0 toward 1; span(lambda) = (1 - lambda) span(0).
- **Continuation.** Shooting on the closed level in reduced coordinates (C, V, L; P = T - C - V - L):
  unknowns (y on the Poincare section, period tau, parameter). Section for each step: the hyperplane
  through the previous converged point normal to the vector field there (fixed during the Newton
  solve of that step). Pseudo-arclength continuation, Newton with the monodromy from the variational
  equations (Radau, rtol 1e-10), parameter derivative by central difference. Recorded per point:
  parameter, period, C amplitude (max - min of C over one period), nontrivial Floquet moduli,
  all balances and their eigenvalues (`ginst.model.classify_balances`).
- **Report** lambda_max, where the branch ends or turns, the span there; whether lambda = 1 is reached.
- **Total continuation.** Draw 12051 in the closed-level total T, both directions; report the T
  interval over which the stable cycle exists.
- **Stop rules.** A branch ends when: lambda reaches 1; the step size falls below 1e-7 (relative)
  without Newton convergence; the period exceeds 1e5; the C amplitude falls below 1e-4; the
  parameter turns (sign change of d(param)/ds); or the K2 CPU cap is reached (then: underdetermined).
- **Classification** of each end from its last >= 8 points and the balances there:
  - Hopf: amplitude -> 0 as sqrt(distance) at finite period; a complex balance pair crosses the axis.
  - Saddle-node on an invariant circle (SNIC): period ~ distance^(-1/2); saddle-node of balances on the orbit.
  - Homoclinic: period ~ ln(1/distance); the orbit approaches a saddle.
  - Fold of cycles: the branch turns in the parameter and a Floquet modulus passes through 1.
  - Otherwise: unclassified, with the data.
  Fits: log amplitude vs log distance (Hopf slope in [0.4, 0.6]); log period vs log distance (SNIC
  slope in [-0.6, -0.4]); period vs ln(1/distance) linear (homoclinic, R^2 >= 0.99 and min distance
  of orbit to a saddle balance < 1e-2 relative). Distance = |p - p_end|, p_end extrapolated from the
  last points.
- Disclosed expectation: the balance at 12051 is an unstable node with real eigenvalues, so the cycle
  there is not near a Hopf point. The type is open.

## K3. The stochastic clock (cap 3 CPU-hours including the harness)

- **Model.** Closed level, all-neighbours count, draw-12051 rates; Gillespie direct method, Kurtz form.
  Propensities (n = counts, N = n_C + n_V + n_L + n_P, x = n_C / N): k1 n_C, k2 n_C,
  k3 n_V F_kr(x), k5 n_L, k6 n_L, k7 n_C, k8 n_P, k10 n_V, k11 n_C F_kc(x).
- **Sizes.** Omega in {10, 25, 50, 100, 200, 400, 800, 1600, 3200}, ascending, as far as the cap
  allows. Each size starts from round(Omega * x_det) at the deterministic cycle's tick point, records
  >= 200 ticks and stops at 1000 ticks (or at the projected cost limit). Before each run, its cost is
  projected from the event rate over its first 1e6 events; a size whose projection exceeds the
  remaining K3 cap is not run (recorded).
- **Tick.** c_mid = 1.340, Delta = 1.146. A tick is an upward crossing of c_C = c_mid after c_C
  has fallen below c_mid - 0.25 Delta = 1.0535 (checked at every event).
- **Measures** per size: ticks; mean period Tbar and CV of the inter-tick intervals; N_coh = 1/CV^2;
  stalls = inter-tick gaps > 5 x 247.53 (and a final censored gap > 5 x 247.53 counts as a stall);
  stall rate per period = stalls / (total time / Tbar); for each stall its start phase
  (t_exit - t_last_tick) / Tbar, where t_exit is the first time after the last tick with
  |c_C(t) - c_C,det(phi)| > 0.25 Delta, phi = (t - t_last_tick) / Tbar, and the deterministic cycle
  c_C,det is aligned on its own tick and taken periodic in phi; c_C(t) is sampled at the events
  (piecewise constant), evaluated on a grid of step 0.05 time units. The number of visits to
  D (n_C = n_L = 0; entries counted).
- **S1.** Fit log CV vs log Omega over sizes with >= 200 ticks and N_coh >= 3 (>= 3 sizes needed,
  else underdetermined). Kill: slope outside [-0.65, -0.35]. Bootstrap 95% interval (2000 resamples
  of intervals within each size, seed 31102026).
- **S2** (measurement): Omega* = smallest Omega in the grid with N_coh >= 10.
- **S3.** Stall rate per period falls with Omega across sizes with stalls. Holds: no larger size
  higher than the next smaller (with stalls) by > 2 Poisson standard errors (SE of the difference,
  sqrt(n)/periods each, combined in quadrature), and the largest such size lower than the smallest.
  Kill: a larger size higher by > 2 SE. Underdetermined: stalls at fewer than 2 sizes.
- **S4.** At the size with most stalls, if >= 50: chi-square of start phases (taken mod 1) against
  uniform over 5 equal bins. p < 0.05: phase-structured. p >= 0.05: kill of part 3 for this grammar.
  < 50 stalls everywhere: underdetermined.

### Harness (must pass before K3 results count)

- **H1 drift.** Omega = 1e5, start on the deterministic cycle at its tick, simulate one period;
  every sampled point (step 0.05) is within 0.01 Delta in C of the deterministic orbit, where the
  reference point is the nearest point of the deterministic orbit (dense, 20 000 points) in the 4-dim
  concentration space (nearest-point distance, not phase matching);
  the first upward tick crossing after t > 0.5 Tdet is within 1% of 247.53.
- **H2 exact.** Omega = 5 (N = 28, 4495 states) and 10 (N = 56, 32 509 states): stationary
  distribution of the closed-level master equation by a sparse solve (numpy/scipy, propensities
  re-implemented independently of the C code). 16 independent chains per size, >= 1e7 events each
  after a burn-in of 1e6 events, time-weighted n_C histograms. Pass if
  TV(pooled, exact) <= TV(chains 1-8, chains 9-16).
- **P1.** Renewal processes, gamma intervals, CV 0.05 and 0.30, 1e4 intervals each (seed 31102026):
  the estimator recovers each CV within 5% relative, and N_coh = 1/CV^2 to match (within 10%).
- **P2.** Brusselator dx = a - (b+1)x + x^2 y, dy = bx - x^2 y at a = 1, b = 1.8 (stable focus),
  same SSA in Kurtz form (0 -> X: a Omega; X -> Y: b n_X; 2X + Y -> 3X: n_X^2 n_Y / Omega^2;
  X -> 0: n_X), Omega in {100, 400, 1600, 6400}. Tick rule rescaled: c_mid = 1 (balance), drop
  threshold 1 - sd, sd = stationary standard deviation of x estimated from the same run after a
  burn-in of 50 time units. 1000 ticks per size. S1's criterion must FAIL (slope outside
  [-0.65, -0.35]).
- **P3.** Synthetic tick series with scripted stalls (known gaps and start phases, constructed
  c_C path): the stall detector and phase extractor report the exact counts, and phases within
  the grid step.
