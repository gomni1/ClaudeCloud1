## PIN — work these next (in order, ahead of anything the run would choose)
- Slit test of the angular-sum handoff, depth D2. Target: Premise Map gap 'What in the handoff can cancel?' (O_signed, reworded 14 Nov). Everything below is fixed before the run; nothing in it may be changed after results are seen. (1) SET-UP: a point source, a barrier with three equally spaced slits A, B, C, each 5 grains wide, and a screen of at least 1001 grains. A history is a straight route from the source through one grain of an open slit to a screen grain; its length L is the route length in step units, not rounded (rounding to whole steps adds phase noise of order ω per route and is not allowed). Choose the distances, the slit spacing and ω before the run so that R2 shows at least 5 fringes across the screen with all three slits open; state them in the report. Each history has weight w = 1. Weights must not depend on which slits are open: a history through A is the same history whether or not B and C are open. No per-configuration renormalisation: the source emits the same amount in every configuration, and P(x) is per unit emitted. (2) GRAIN RULE: each step turns the carried orientation by a fixed angle ω; a history of length L arrives with orientation θ = ωL. The grain has no up or down, so θ is an axis, defined mod π; represent it by the doubled-angle unit vector u = (cos 2θ, sin 2θ). At a screen grain x the arriving contributions add: R(x) = Σ w·u over all histories reaching x through the open slits. (3) READOUTS, all fixed now and all reported: R2, P(x) = |R(x)|²; R4, P(x) = |R(x)|⁴; RS, P(x) = 1 − exp(−|R(x)|²/s) with s set before the run to the median of |R|² over the screen with all three slits open. CONTROLS: C+, the positive-weight rule P(x) = Σ w over arriving histories (no orientation); C-arrow, the same as R2 but with θ an arrow, mod 2π, u = (cos θ, sin θ). (4) MEASURES: for every readout and control, compute P for all 8 slit configurations (P0 = 0 with all closed unless a background is declared before the run), I2(jk)(x) = P_jk − P_j − P_k + P0 for each pair, and I3(x) = P_ABC − P_AB − P_AC − P_BC + P_A + P_B + P_C − P0. Report κ2 = Σx|I2| / Σx P_ABC (summed over the three pairs) and κ3 = Σx|I3| / Σx(|I2(AB)| + |I2(AC)| + |I2(BC)|). (5) HARNESS CHECKS, which must pass before any candidate result counts: C+ gives I2 = 0 and I3 = 0 to float tolerance (the positive-weight theorem); R4 and RS give κ3 > 10⁻³ (planted failures, so the test can see third-order terms). If either check fails, report a harness failure and stop. (6) KILL LINE for the candidate (angular sums read as R2): κ2 < 0.05 (no material interference) or κ3 > 10⁻⁶ (third-order terms beyond float error). Exotic looped paths are not in this model, so no allowance is made for them. (7) ALSO REPORT: the fringe spacing on the screen for R2 and for C-arrow at the same ω and slit spacing, and their ratio (the doubled-angle check: an axis should give fringes at half the spacing of an arrow for the same ω). (8) SECOND PART, same depth, only if part one passes its harness checks: add turnover noise, a random orientation jitter of standard deviation σ per step, independent between histories; for σ on a grid fixed before the run from 0 to π/2, report κ2 and κ3 for R2 averaged over at least 200 noise draws. Expected shape, stated now: κ2 falls toward 0 as σ grows; κ3 stays at float level. Report what happens, whichever way it goes. (9) SCOPE OF A RESULT: R2 gives I3 = 0 by algebra, since only pairs cross. A pass therefore shows the candidate shape is consistent with both slit anchors and that the test separates readouts; it does not derive the squared readout, and the report must say so. A failure is about this rule and these readouts only. Observational-register anchors: Sorkin 1994; Sinha et al. 2010 (third-order term below 10⁻² of second-order).
