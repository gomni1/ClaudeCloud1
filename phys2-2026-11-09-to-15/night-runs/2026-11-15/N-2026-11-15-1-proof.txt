N-2026-11-15-1 — working notes and the radial proof (as sent to the checker)

Setting. P: R^2 -> R continuous, P(0) = 0.
I3(a,b,c) = P(a+b+c) - P(a+b) - P(a+c) - P(b+c) + P(a) + P(b) + P(c) - P(0).
Hypothesis H1: I3(a,b,c) = 0 for all UNIT vectors a, b, c (and nothing is assumed for other sizes).
Question: must P = l(x) + x^T M x on |x| <= 3 ?

1. Mode reduction (exact). If P satisfies H1 so does P∘U for any rotation U, and H1 is linear in P. So the
   angular Fourier components P_m(x) = f_m(r) e^{i m phi} each satisfy H1 (complex-valued version).

2. Known solutions: constants (the -P(0) term makes them cancel: 1-3+3-1 = 0), linear functions, quadratic forms.
   In modes: m=0: {1, r^2}; m=±1: {r}; m=±2: {r^2}.

3. Numerics (N-2026-11-15-1-nullspace.py): Chebyshev basis in r on [0,3], degree K, 4000 random unit triples.
   Null directions (normalised singular value < 1e-9): m=0: 2, m=1: 1, m=2: 1, m=3..8: 0, at K = 20, 30, 40.
   No value between 1e-9 and 1e-4. The smallest non-null values are ~1e-2 and fall slowly with K
   (m=0: 1.9e-2, 1.2e-2, 8.4e-3 at K=20,30,40). Plants tripped (see stdout).

4. Useful identity for unit complex numbers a,b,c (e1 = a+b+c, e3 = abc):
   (a+b)(b+c)(c+a) = e1*e2 - e3 with e2 = ab+bc+ca = e3*conj(e1), so
   |a+b| |b+c| |c+a| = | |a+b+c|^2 - 1 |,   and   |a+b|^2 + |b+c|^2 + |c+a|^2 = |a+b+c|^2 + 3.

5. Radial case, proof. P = f(|x|). Put s_i = |pair sum|^2 in [0,4], rho^2 = |a+b+c|^2, g(s) = f(sqrt s).
   H1 reads g(rho^2) - g(s1) - g(s2) - g(s3) + 3 g(1) - g(0) = 0, with s1+s2+s3 = rho^2 + 3 and
   s1 s2 s3 = (rho^2 - 1)^2. So sum_i g(s_i) must be constant along each curve
   {s1+s2+s3 = const, s1 s2 s3 = const} inside the attainable surface.
   Angle form: with A, B the angles from a to b and from b to c (so a to c is A+B),
   F(A,B) = h(cos A) + h(cos B) + h(cos(A+B)), h(t) = g(2+2t), must be a function of
   S = cos A + cos B + cos(A+B). For f twice differentiable on (0,2]: F_A S_B - F_B S_A = 0.
   Write k(A) = -d/dA h(cos A) = f'(2 cos(A/2)) sin(A/2) (for 0 <= A <= pi). The condition is
     (k(A) + k(A+B)) (sin B + sin(A+B)) = (k(B) + k(A+B)) (sin A + sin(A+B)).
   It holds identically at B = 0. Its B-derivative at B = 0, with lambda = k'(0), gives
     k'(A) sin A - (2 + cos A) k(A) = -2 lambda sin A.
   General solution: k = lambda sin A + gamma sin A tan^2(A/2).
   In terms of f: f(r) = alpha + (lambda/2)... i.e. f = alpha + beta r^2 + gamma' (4 ln r - r^2/2).
   The ln r term is not continuous at r = 0 (r = 0 is attained: a = -b). So gamma' = 0 and
   f = alpha + beta r^2 on [0,2]. On (2,3], f(rho) is then fixed by H1 from values on [0,2], and since
   alpha + beta r^2 satisfies H1 it is the value: f = alpha + beta r^2 on [0,3]. P(0)=0 gives alpha = 0.
   Status: [theorem, radial P, f in C^2(0,2] and continuous at 0]. (The ODE is only a necessary condition;
   it is enough because its solution set is already inside the known solutions plus one excluded function.)

6. Not proved: the non-radial modes (numerics only), and P merely continuous (smoothing by rotation keeps H1,
   smoothing by translation or dilation does not, so regularity in r cannot be gained for free).
