## Answers to the three questions

1. **Which stratum a section must pass through for the field to carry a half-twist.** For rigid-sector loops with retraced transitions, it must pass through the closed stratum C2, that is, sections with even stabilizer order (C2° or C4°). Beyond that class of loops the twist is not fixed without a further choice (stop S1). Within it, the twist's fractional part is generated by 1/k over the strata where identifications occur, so passing only through odd strata (C1, C3, C5) cannot give ½. A passage through the circle permits any fraction, because its stabilizer is all of SO(2), so the circle does not quantize anything.
2. **Where an orientation winding can change.** For a fixed orientation map, the winding changes only where the loop crosses that map's singular set. That set always contains every symmetric stratum (proved). For M ≥ 4 it must also contain asymmetric sections (proved; M = 4 by proof only, not computed), and the M = 5 witnesses show windings changing at sections with g = 1 and stratum distance ≥ 0.02. For M ≥ 5 there is no map-free integer winding of asymmetric loops at all. In a section space with a single odd mode, the map-free C2 invariant D_3 changes only at C2 crossings.
3. **Whether B is forced into the half-turn-symmetric stratum.** Under attribution S (the class whose symmetry closes the half-turn carries it), yes: S_B must be even, C2 or C4 (both inside closed C2). For rigid-sector loops with retraced transitions this is forced *[post-freeze audit correction: scope added]*, but C2° is not singled out over C4°. Much of this result comes from the definition of attribution S itself, which ties carrying to the closing symmetry. The topological content is the closure lemmas P5 and P6: a half-turn closes only through an even stabilizer. S_A is underdetermined. The premise's asymmetry (A cannot carry the half-twist) is topological only if S_A is odd. (C1, C2) is the lowest-codimension member, which is a genericity preference and not forced. Under attribution R (the class that rotates carries it), B is not forced, and the rotation can be moved continuously between classes.

## Proofs (exact statements and arguments)

**P1. Stabilizer obstruction.** Let θ : U → ℝ/2πℤ be continuous on an invariant set U ⊂ V_M with θ(R_β z) = θ(z) + wβ. Then U contains no z ≠ 0 with g(z) ∤ w, and U does not contain 0. *Proof.* R_(2π/g) fixes z, so θ(z) = θ(z) + 2πw/g mod 2π, which forces g | w. At 0 every R_β fixes z, so w = 0. ∎ In particular, a weight-1 map is undefined on every C_k (k ≥ 2). On C2° an orientation exists only mod π (w = 2), which is the premise's "two conjugate presentations". The sympy check verifies the weights of θ_P, θ_R, θ_P′, ψ_2 and that θ_P and θ_R vanish identically on every C_k.

*[Post-freeze audit correction.]* The statement "orientation exists only mod π" is pointwise. A global weight-2 map on C2° does exist, namely ½ arg z₂, since z₂ ≠ 0 on C2° for M ≤ 5. At C4° sections (z₂ = 0, z₄ ≠ 0) even a weight-2 map is forbidden, because g = 4 does not divide 2.

**P2. Codimension.** C_k is the linear subspace {z_m = 0 : k ∤ m}, so its real codimension is 2#{m ∈ [2, M] : k ∤ m}. For k ≥ 2 and M ≥ 3 this is ≥ 2, because the set contains 3 or 2. ∎

**P3. No global orientation map on the asymmetric stratum.**
- (a) M ≥ 5. V ∖ V_free = ∪_{p prime ≤ M} C_p, and each C_p has real codimension ≥ 4: for p = 2 the odd modes {3, 5, …} count ≥ 2; for p ≥ 3 the set {m : p ∤ m} contains at least three modes. The complement of finitely many linear subspaces of codimension ≥ 3 is simply connected by general position. So the orbit loop β ↦ R_β z₀ is null-homotopic in V_free. Any weight-1 θ on V_free would give it degree 1, but a null-homotopic loop has degree 0, so no such θ exists. Every free-homotopy invariant of loops in V_free is constant. ∎
- (b) M = 4. V_free = V ∖ (C2 ∪ C3), with C2 = {z_3 = 0} of codimension 2 and C3 of codimension 4. So π₁(V_free) ≅ π₁(ℂ² × ℂ*) = ℤ via deg z_3. The orbit loop has deg z_3 = 3, so no homomorphism to ℤ sends it to 1. ∎ (Proof only; M = 4 was not computed.)
- (c) M = 3. V_free = ℂ* × ℂ* and θ_P is defined on all of it. Windings are V_free-homotopy invariants, but they depend on the map: θ_P′ − θ_P = arg(z_2³ z̄_3²) has nonzero degree on some loops. W_θ − W_θ′ is the degree of a rotation-invariant phase along the shape loop, so it vanishes for rigid loops and not in general. ∎

**P4. Flip.** For s ∈ C_k and u supported on {m : k ∤ m}, R_(2π/k)(s + εu) = s + ε R_(2π/k) u. For k = 2, R_π u = −u. So the continuous body path s + εu → s → s − εu (teardrop → ellipse → flipped teardrop) ends at R_π of its start without passing the circle. ∎ (sympy, k = 2, 3, 4.)

**P5. Rigid closure.** R_x s = s iff x ∈ (2π/g(s))ℤ. *Proof.* By Bézout, 1 = Σ n_m (m/g) over the active modes, so m x ∈ 2πℤ for every active m forces g x ∈ 2πℤ. The converse is immediate. ∎ A rigid field closes with twist T iff T ∈ (1/g)ℤ, so a half-integer twist of a rigid field needs g even. *[Post-freeze audit correction: scope.]* This closure criterion is for a single rigid section, that is, the orbit of one fixed s ≠ 0. It does not by itself cover a loop whose shape changes between strata; that case is P6.

**P6. Sector closure.** Take a rigid-sector loop whose transitions are retraced, so each transition appears once as τ and once as R_δ τ reversed.
- (a) For every invariant inner product, A_w = 2πT. The connection form is rotation-invariant, so the contributions of τ and of R_δ τ reversed cancel; inside sectors the motion is pure rotation. *[Post-freeze audit correction: conditions.]* This needs exact retracing, a positive-definite invariant inner product, and a nonzero denominator ⟨ξγ, ξγ⟩_w, which holds away from the circle.
- (b) *[Post-freeze audit correction: reworded.]* The loop closes geometrically iff some choice of listed relabels satisfies T + Σ j/k ∈ ℤ. For a fixed choice of relabels, the accumulated representative returns iff the congruence holds; that version is bookkeeping (P5 applied to the accumulated representative). The reason for the change is Astra's counterexample: "A constant closed loop with a k=2 sector admits a harmless representative relabel j=1, while T=0. It remains closed, yet T+j/k=1/2 ∉ ℤ." The original wording, "the loop closes with every identification listed iff T + Σ_i j_i/k_i ∈ ℤ", is in commit `5c3f4d2`.
- (c) Hence an A–B–A loop with T = ½ and c_A = 0 that uses identifications only at B exists iff k_B is even, and one using identifications only at A exists iff k_A is even.

This is exact. The 16-cell enumeration is a numerical confirmation of it. ∎

*[Post-freeze audit correction: explicit construction for P6(c).]* Astra judged P6(c) false as an existence theorem: after a half-turn at B, the return "returns along the rotated path to R_πρ_A≠ρ_A, not along the exact reverse of the original transition". The construction below answers that.
- **Construction.** M = 3, ρ_A = (z₂, z₃) = (0.30, 0.20i) (g = 1) and ρ_B = (0.35, 0) (g = 2). The loop is the straight path τ from ρ_A to ρ_B, then R_(πu) ρ_B for u ∈ [0, 1], then τ reversed exactly.

  - the joint is continuous, |R_π ρ_B − ρ_B| = 8.6e−17;
  - the loop closes;
  - A_w/2π = 0.49999999996 for both w ≡ 1 and w_m = m²;
  - the minimum section norm is 0.340, so the loop avoids the circle. Claude's standalone check reported 0.35. The harness minimum lies along τ, at about its midpoint, not at ρ_B.
- **Control.** With ρ_B = (0, 0.35), in C3, the joint tears with gap 0.70.
- **Reading.** Astra's counterexample leaves out R_π ρ_B = ρ_B. Once B is half-turn symmetric, the return can be the exact reverse of the outgoing path.

**P7. One odd mode.** *[Post-freeze audit correction: restated with the passage convention explicit. The original wording is in commit `5c3f4d2`.]* If exactly one odd mode q is active, V ∖ C2 ≅ ℂ^even × ℂ*, and D_q = deg z_q generates π₁ ≅ ℤ.

(a) **Locked-passage convention.** z_q enters and leaves each C2 arc along ±u in the co-rotating frame. This is the only case definition 1.8 covers, and every N₃ deformation in the run already satisfies it. At a flip passage the two minimal resolutions differ by one meridian. Under this convention N_q = D_q(up) + D_q(down) is an integer invariant under deformations that keep the C2 arcs in C2 and everything else off C2. Also N_q ≡ number of flip passages (mod 2), and on rigid loops N_q = q·2T.

**Why Astra's counterexample is not a deformation in this class.** Astra adds one full winding of z_q on an off-C2 excursion. With the C2 arcs fixed and the passage directions locked, z_q cannot gain a winding without passing through zero, which would put a section off the arcs into C2.

(b) **Free passage.** If the passage direction is free, a flip can be deformed into a non-flip, and N_q changes by ±1, so its parity is not invariant either. This is the new post-freeze claim H4a-free. Witness (`strata/audit.py`, `tests/test_audit.py`):

- Every section off the B arc has z₂ ≠ 0 and z₃ ≠ 0 (asserted).
- The B arc is resolved along the minimal co-rotating detour wrap(ψ + π), taking both detours (±π) when that angle is exactly π. Every resolution keeps d₂ ≥ 0.06.

The map-independence clause below stands under the convention of (a). Map-independence of the parity (M = 3): π₁(V_free) = ℤ² with orbit (2, 3) and meridian (0, 1). The half-loop H (half orbit closed by half a meridian) satisfies 2H = orbit ± meridian. So every homomorphism h with h(orbit) = 0, which covers every difference of two weight-1 maps, has h(meridian) = ±2h(H), which is even. ∎ (sympy: h = λ(−3, 2), h(meridian) = 2λ.)

**P8. Two or more odd modes.** If O ≥ 2 odd modes are active, V ∖ C2 ≅ ℂ^even × (ℂ^O ∖ 0) ≃ S^(2O−1), which is simply connected. The minimal resolutions of a flip passage are therefore homotopic off C2. When the even part is nonzero they are homotopic inside V_free, because gcd(2, odd) = 1. No resolution-based half-integer invariant exists. *[Post-freeze audit correction: narrowed.]* No invariant distinguishing the two local resolutions comes from this topology; invariants that use extra structure are not excluded. ∎ (The witness family is P_μ(λ) = cos(πλ)u + sin(πλ)w_μ, with w_μ running from iu to −iu through (−z̄_5, z̄_3).)

**P9. Three-fold symmetry.** If γ(t + 2π/3) = R_α γ(t), then any rotation-invariant class function c satisfies c(γ(t)) = c(γ(t + 2π/3)), because rotation preserves g. So the three sectors carry the same class, and the twist contributions are equal (rotation preserves the sense of continuous rotation). No 2 : 1 pattern exists, whether A–B–A or B⁺–A–B⁻. A 2 : 1 pattern must break ℤ₃. ∎

## Stopped: choices that would be needed

- **S1. Twist of a shape-changing field.** Continuity and closure fix the twist only for rigid sectors with retraced transitions. For a non-rigid field the twist depends on a gauge (which orientation map) or on a connection (an inner product, or a zero-angular-momentum-type rule, which is dynamics). In the H1b homotopy at s = 0.75 the map windings are −2, −4, −2 and the connection twists are 0.6815 and 0.5790 for the two weightings. Not decided.
- **S2. Non-retraced transitions.** Entering and leaving a sector by different shape paths adds a connection holonomy (the loop area in shape space times curvature), which is a dynamical quantity. Not decided.
- **S3. Attributing the half-twist to a class.** Topology forces only that some section with even stabilizer occurs on the loop. Which class "carries" the twist is a definitional choice. S is the only deformation-invariant option tested. The premise's wording does not fix it.
- **S4. Odd-mode content of admissible sections.** Whether the unpaired half-twist is topologically protected (H4a) depends on whether sections carry one odd mode or several. Topology does not choose. *[Post-freeze audit correction.]* It also depends on whether the passages are locked (P7(a)) or free (P7(b)).
- **Underdetermined, not a dynamical choice:** S_A (H3). Requiring the premise's A/B capability asymmetry to be topological would force S_A odd. That requirement is an added input.

## Where writhe and Călugăreanu would re-enter

All twists here are measured in the plane of a planar centreline, a frame with zero holonomy. For a non-planar centreline the frame must be specified (for example by parallel transport), and for a closed band Lk = Tw + Wr. A half-integer T with C2 sections makes the section-axis band a Möbius-type, non-orientable band, whose self-linking becomes half-integer. That is the point where Călugăreanu's theorem would enter.
